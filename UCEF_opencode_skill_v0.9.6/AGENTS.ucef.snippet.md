## UCEF business-chain analysis

Use the `ucef` skill for Java business execution excavation. UCEF uses an explicit independent analysis workspace; Java projects are registered read-only data sources. Build a short TraceStage business spine, close named CoverageGates with cross-method ImplementationSlices, and keep execution nodes/field lineage as expandable implementation evidence. Checkpoint once per state-changing semantic probe, not per low-level tool call. Skeleton, Slice, and Integration Workers return bounded deltas; the runtime is the single writer. A deliverable must remain readable by a Java developer unfamiliar with the system while exposing field origins, transformations, persistence, external request/response provenance, configuration routes, and explicit gaps.
